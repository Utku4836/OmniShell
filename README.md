# Black Application (Siyah Uygulama)

A minimalist, frameless terminal hub and isolated launcher for AI coding agents and media CLI utilities.

## Features

- **Minimalist Aesthetic:** Borderless, dark-themed interface with smooth keyboard and mouse navigation.
- **Isolated Sandboxes:** Every CLI tool runs inside its own isolated system/<ToolName> directory with sandboxed HOME, USERPROFILE, APPDATA, and XDG environments.
- **Built-in Package Provisioner:** One-click / one-key automatic installation for npm, pip, and PowerShell-based CLI tools.
- **Embedded Terminal:** High-performance xterm-based rendering with custom context menus, seamless multi-window support, and terminal auto-fit.

## Getting Started

1. Double-click start.bat to launch the application.
2. If dependencies are missing, start.bat will automatically perform initial setup and open the app.
3. Use Arrow keys or mouse to browse tools. Press ENTER to launch or install any tool.
