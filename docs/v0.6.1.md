# OmniShell 0.6.1

The launcher now uses a focused vertical list on the left side of the window, with the ASCII wordmark on the right. The selected CLI is shown at full size, adjacent entries use a medium scale, and the rest recede while remaining in the same keyboard-controlled list.

Selection changes use composited scale and opacity transitions. Native scrolling keeps the focused entry centered, and updates are grouped into one animation frame. The list does not rebuild its DOM or animate layout dimensions while moving between tools.

Opening a CLI crossfades from the launcher into the terminal. Closing a session starts the reverse transition immediately while the process finishes its bounded shutdown. Window open, restore, minimize, hide, and close actions share the same short motion language; the main process uses a completion timer instead of changing window opacity every frame.

When a CLI exits on its own, primary and auxiliary windows remain open with the same session-ended message. `Enter` restarts the profile. The context menu remains available for closing the session or its window.

Reduced-motion preferences remove spatial movement while preserving clear state changes.
