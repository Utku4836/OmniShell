# OmniShell 0.6.2

This release improves runtime isolation, installer reliability, and interface interactions across the home launcher and profile settings.

## Installer and environment resolution

- Normalizes environment variable keys on Windows to prevent mixed-case `Path` entries from shadowing system Node.js and npm executables.
- Adds multi-directory discovery for npm in PowerShell installer routines, falling back to standard Program Files and AppData locations when not present in the active PATH.
- Improves error reporting during tool installations by parsing meaningful error lines from process output rather than generic failure markers.

## Launcher and profile navigation

- Refines home screen tool list scaling to emphasize the active selection while keeping neighboring entries uniformly sized.
- Adjusts active item dimensions to ensure long tool names display clearly without clipping.
- Updates profile list selection: a single click selects the active profile to view and edit its settings, while a double click or `Enter` launches the terminal session.
